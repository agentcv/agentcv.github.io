Set up agentCV with ChatGPT Codex

Codex is OpenAI's coding agent. It works in a folder on your computer and reads agentCV's operating manual on its own.

Codex support is new and less tested than Claude. If something doesn't work, please tell us in GitHub Issues.

What you need

  • A ChatGPT plan that includes Codex. OpenAI's Codex page lists which plans do.
  • A Mac, Windows or Linux computer with Python 3.9 or newer.
  • Your LinkedIn profile, saved as a PDF (step 3 shows how).

Steps

  1. Install Codex

    Follow the install instructions on OpenAI's Codex page. In a terminal, the usual command is:

    npm install -g @openai/codex

    That needs Node.js. OpenAI also offers an app and editor extensions; any of them works if it can open a folder on your computer.

  2. Download agentCV

    Go to the latest release

    Under Assets, download agentcv-<version>.zip and unzip it. You get a folder called agentcv. Move it somewhere private, like your Documents folder. You only download once; later updates come through your agent.

  3. Add your LinkedIn profile

    On your LinkedIn profile page, select More, then Save to PDF. Put that PDF, and your current resume if you have one, in agentcv/profile/materials/.

  4. Open the folder in Codex

    In a terminal, go to your agentcv folder and start Codex:

    cd ~/Documents/agentcv codex

    Sign in with your ChatGPT account when it asks.

  5. Paste the starter prompt

    You're my job search agency, and I'm your only client. Read AGENTS.md in this folder: it's your operating manual. This is our first session, so start setup at Phase 1. Read my LinkedIn PDF and resume in profile/materials/, then interview me a few questions at a time. Coach me to a strong primary resume, help me update LinkedIn to match it, and then ask me what jobs and industries I want to target. Don't send, submit or post anything without my explicit OK.

Permissions to allow

  • Running the Python scripts in scripts/. They build your resumes, PDFs, job sweeps and dashboard.
  • Internet access for job sweeps and agentCV updates. Codex may ask before it goes online; allow it for those tasks.
  • Keep Codex working in the agentcv folder only.

What happens next

Setup runs in four phases over one to three sessions:

  1. Intake: your agent reads your LinkedIn and resume, then asks about the gaps: numbers, scope, team size.
  2. Primary resume: it coaches you bullet by bullet to a resume built for applicant tracking systems, using only facts you confirm.
  3. LinkedIn: it writes matching LinkedIn copy for you to paste in. It never edits LinkedIn itself.
  4. Targets: it asks what roles, industries, pay and location you want, then builds your job board list and runs the first search.

After that, open the same folder each day and say "start my morning." Say "done for today" when you finish.
